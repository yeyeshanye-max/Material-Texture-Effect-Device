# Material Texture Effect Device

一个网页端材质肌理效果器，用于给图案快速添加粗糙刻印和撕边肌理效果。

用户可以上传 PNG / JPG 图片，并通过参数调整效果。工具也支持上传自定义肌理 PNG，用于生成更丰富的肌理变化。

## Effects

目前支持两种效果：

1. **Rough Copperplate Engraving**
   粗糙铜版刻印效果

2. **Torn Texture Engraving**
   撕边肌理刻印效果

## Features

* 上传 PNG / JPG 图片
* 上传自定义肌理 PNG
* 实时预览效果
* 调整效果参数
* 支持反相选项
* 导出处理后的图片

## Usage

1. 上传一张 PNG / JPG 图片
2. 选择一种效果
3. 根据需要上传肌理 PNG
4. 调整参数
5. 预览效果
6. 导出图片

## Local Development

Clone the repository:

```bash
git clone https://github.com/yeyeshanye-max/Material-Texture-Effect-Device.git
```

Enter the project folder:

```bash
cd Material-Texture-Effect-Device
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local address shown in the terminal.
